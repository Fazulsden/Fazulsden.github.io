04 — About

Finds the gap, writes the report.

I'm Fazul, an offensive security researcher working in the field since 2019 and a full-time bug bounty hunter since 2026. My work sits where access control and trust boundaries break down — the exposed credential accepted as an insider, the parameter that should have been checked, the recovery flow that trusts the wrong thing.

I've reported critical issues to enterprise, e-commerce and gaming targets, including a critical Samsung Pass finding rewarded through Bugcrowd, and I run large-scale exposure research now in coordinated disclosure. I also go lower: interrupt-injection attacks on confidential VMs, kernel-level cryptography, and Web3 contract auditing.
