02 — Research & Projects

Security from the silicon up.

Beyond bug bounty: low-level security research, applied cryptography, and Web3 auditing.

Confidential Computing

Attacking & Defending Confidential VMs

Built a testbed on AMD EPYC to reproduce hypervisor interrupt-injection attacks (HECKLER class) against AMD SEV-SNP and Intel TDX trusted execution environments, then proposed Guest_Defense — a guest-side mitigation validating that incoming interrupts match expected CPU state. Included reverse-engineering production Windows software to map control flow and licensing behavior.

SEV-SNP / TDXQEMU / QMPReverse engineeringPython
Systems / Cryptography

SHA-256 across kernel, user space & syscalls

Implemented SHA-256 three ways — a loadable kernel module over the kernel crypto API, a user-space build over OpenSSL, and a custom system call — across three purpose-built Linux kernels. Benchmarked the boundary-crossing overhead and analyzed the attack surface of running crypto in ring 0 versus user space.
